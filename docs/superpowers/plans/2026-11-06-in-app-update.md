# 应用内下载和安装更新

**目标：** Windows 安装版点击更新后在应用内下载完整 NSIS 安装包，校验成功后由用户点击重启安装，无需访问 GitHub 页面。2.2.1 / 2.2.2 首次升级仍需手动安装。

**实现：** 使用 electron-updater 6.x，保留现有 Release 检测与更新面板；主进程掌握更新源和安装文件，renderer 不传文件路径或下载地址。下载沿用仓库配置的 HTTPS 加速线路并回退直连，不下载资源补丁。安装前保存状态，完成现有壁纸退出清理后交给 NSIS。

1. 为更新控制器和面板编写失败测试，覆盖重复点击、下载失败重试、校验失败、未就绪禁止安装、进度及浏览器备用入口。
2. 接入主进程更新控制器、可信 IPC、preload 和现有面板，保留原开场与无关行为。
3. 更新受影响的回归检查与说明，准备 2.2.3 本地安装包；线上已发布版本仍如实标注为 2.2.2。
4. 执行更新相关回归、快速检查和打包校验；用隔离测试校验真实下载完整性，不在用户安装目录实际覆盖。未明确授权前不发布 Release，不修改线上 About。

**结果：** 本地功能与 2.2.3 安装包完成，29 项更新检查、快速检查、隔离主入口启动及包内版本/哈希核对通过。完整渲染检查的两项歌词排版失败与实际覆盖安装未测范围记录于 `docs/IN_APP_UPDATE_2.2.3.md`。版本与校验信息只从官方 HTTPS 获取，加速站仅运输安装包；未提交或发布。

**交付调整：** 用户要求本次仅提交源码，不发布安装包，留待下次与其他改动一起打包。此前本地构建作为验证记录保留，下次发版重新构建并核对；不创建版本标签或 GitHub Release。
